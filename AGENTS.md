# Expo: this project is pinned to SDK 54

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code. Expo's APIs move between SDK versions — the current docs on
docs.expo.dev describe a newer SDK than this project runs, and code written
against them will not work here.

**Do not upgrade the Expo packages.** SDK 54 is what the owner's Expo Go build
supports; upgrading means the app can no longer be tested on their phone. See
the troubleshooting section of `OWNER_GUIDE.md`.

Already-known SDK 54 specifics:

- `expo-av` is gone. Recording and playback both use **`expo-audio`**.
- `expo-file-system` uses the new `File`/`Paths` API; the old one is at
  `expo-file-system/legacy` (which `src/services/whisper.ts` still uses).
- `expo-speech-recognition` needs a dev/EAS build. In Expo Go the native module
  is absent, so `src/services/stt.ts` falls back to record → Whisper.
- Expo Router's typed routes are generated by the **dev server** into
  `.expo/types/router.d.ts`. After adding a screen, run `expo start` once or
  `tsc` will reject the new route path.

Before committing, all three must be clean:

```bash
npx tsc --noEmit
npm run lint
npx expo export --platform android
```
